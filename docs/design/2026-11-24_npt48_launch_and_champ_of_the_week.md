## ส่วน A: กันแอดมินลบหรือเพิ่มอะไรผิดพลาด

เมื่อไม่แยกสิทธิ์ตามวงแล้ว ความปลอดภัยจะมาจาก 3 ชั้นนี้แทน ใช้กับแอดมินทุกคน (รวมเอ็มมี่)

### A1. บันทึกการทำงานของแอดมิน (Audit log)
- ตารางใหม่ `admin_audit_log` เก็บข้อมูล: ใคร, ทำอะไร, กับรายการไหน, ข้อมูลก่อนแก้ (jsonb), เวลา
- ฟังก์ชันช่วย `_admin_log(admin, action, target_table, target_id, before)` เรียกจาก RPC `admin_*` ทุกตัวที่ลบหรือแก้ข้อมูล
- หน้าใหม่ `admin_audit.html` ดูย้อนหลังได้ กรองตามแอดมิน / ประเภท / วันที่

### A2. ถังขยะ (Soft delete) สำหรับของที่ลบแล้วเสียหายมาก
- เพิ่มคอลัมน์ `deleted_at`, `deleted_by` ให้: posts, vote events, theater events, campaigns, gifts, redeem codes, collections
- RPC ลบ = ตั้ง `deleted_at` แทนลบจริง ส่วนหน้าแสดงผลกรองด้วย `deleted_at is null`
- หน้า `admin_trash.html` กู้คืนได้ภายใน 30 วัน cron ล้างถาวรหลัง 30 วัน
- ข้อควรระวัง: ทุก RPC ที่ select จากตารางเหล่านี้ต้องเพิ่มตัวกรอง ก่อนลงมือต้องนับจำนวนฟังก์ชันที่โดนผลกระทบให้เอ็มมี่ดูก่อน

### A3. ยืนยันก่อนลบในหน้าเดียวกัน (ไม่ใช้ป๊อปอัป)
- ปุ่มลบจะเปิดกล่องยืนยันในหน้า ต้องพิมพ์ชื่อรายการให้ตรงก่อน ปุ่มยืนยันถึงจะกดได้
- การเติมเงินหรือโอน Token ที่ยอดสูงกว่าเกณฑ์ (เช่น 1,000) ต้องยืนยันซ้ำอีกครั้ง

> ไม่ต้องทำ `admin_group` แล้ว เพราะเอ็มมี่เลือกไม่แยกสิทธิ์ แอดมิน NPT48 ใช้ `is_admin = true` แบบเดียวกับ [[blm48-dual-role-admin]]

## ส่วน B: เปิด NPT48 เต็มแอป

ตอนนี้ NPT48 (M032–M046) ถูกกรองด้วย `coalesce(group_name,'BLM48')='BLM48'` ใน:
`get_all_members`, `get_ranking_full`, `get_fan_boards`, `_extract_mentioned_members`,
`admin_get_member_dashboard`, `get_winner_theme` (รายชื่อวันเกิด),
`send_member_gift` (ส่ง Gift ให้ NPT48 ไม่ได้ — เพิ่ม 2026-11-25) และแท็บ NPT48Design ที่ซ่อนอยู่ใน `member-gift-sheet.js`

### วิธีออกแบบให้กดเปิดวันเดียวได้ทันที
- ตารางใหม่ `app_settings(key text primary key, value jsonb)`
- ฟังก์ชัน `member_group_visible(p_group text) returns boolean`
  = `p_group = 'BLM48'` หรือ `app_settings['npt48_full_launch'] = true`
- แก้ตัวกรองทั้ง 6 จุดให้เรียก `member_group_visible(group_name)` ทำล่วงหน้าได้ ผลยังเหมือนเดิมจนกว่าจะเปิด flag
- **วันเปิด:** รัน `update app_settings set value='true' where key='npt48_full_launch'` คำสั่งเดียว
- ปิดกลับได้ทันทีด้วยคำสั่งเดียวกัน (`false`)

### งานฝั่ง client ที่ต้องเช็กก่อนวันเปิด
- แคชรายชื่อเมมเบอร์ใน localStorage (common mention cache) ต้องเปลี่ยนชื่อ key หรือเพิ่มเวอร์ชันแคช เพื่อให้ทุกเครื่องโหลดใหม่
- กรอบรูปตามวงใช้ `groupFrameColor()` อยู่แล้ว
- Member Ranking / Kami-Oshi / Search: เพิ่มแท็บหรือตัวกรอง "ทั้งหมด / BLM48 / NPT48"
- รูปโปรไฟล์ NPT48 ตอนนี้เป็นลิงก์ lh3 Google ต้องเช็กว่ายังโหลดได้ หรือย้ายไปที่เก็บรูปของแอป

เลื่อนวันได้โดยไม่ต้องแก้โค้ด

### C2. ข้อมูล (Supabase)

**`ranking_weekly`** `(member_name text, week_start date, cookies numeric, primary key(member_name, week_start))`
- `week_start` = วันอาทิตย์ของสัปดาห์ (เวลาไทย) คำนวณด้วย `_bkk_week_start(ts)` = `d - extract(dow from d)` (dow ของวันอาทิตย์ = 0)

**วิธีสะสมคะแนน: ฟังก์ชันกลาง `_credit_member_cookies()`** (รายละเอียดในส่วน D)
~~แบบเดิมใช้ trigger บน `ranking_monthly`~~ ยกเลิก เพราะเอ็มมี่กำหนดว่าไลก์/คอมเมนต์ต้องปิดเป็นรายสัปดาห์ด้วย trigger จึงแยกไม่ได้ว่าคุกกี้มาจากโพสต์ของสัปดาห์ไหน
- ทุกวงนับรวมกันในอันดับเดียว และไม่นับก่อน `weekly_count_from`

**`champ_of_the_week`** (โครงเหมือน `champ_of_the_month` เพื่อใช้โค้ดโพสต์ขอบคุณร่วมกัน)
`id, week_start date unique, week_end date, name, group_name, total_cookie, message, post_image, post_image_fallback, post_id, created_at`

**`auto_record_champ_of_the_week(p_week_start date default null)`**
- cron `10 17 * * 6` (UTC) = วันอาทิตย์ 00:10 เวลาไทย
- บันทึกสัปดาห์ที่เพิ่งจบ: อันดับ 1 = cookies มากสุด ถ้าเท่ากันเรียงตามชื่อ (กติกาเดียวกับรายเดือน)
- ส่งแจ้งเตือนในชื่อ "BLM48" (ตามกฎ [[feedback_blm48_no_role_split_wording]])

**`get_champ_of_the_week()`**: รูปแบบผลลัพธ์เหมือน `get_champ_of_the_month` และเพิ่ม `weekStart`, `weekEnd`, `weekLabel` (เช่น "3–9 Jan 2027")

### C3. ธีมแอปตามซิงเกิลของวงที่ชนะ

ตอนนี้ `applyGroupTheme()` ใน `common.js` เปลี่ยนสีตามวงของ Champ เดือนล่าสุด โดยใช้ `GROUP_THEMES` ที่เขียนตายตัวไว้ (NPT48 ฟ้า / BLM48 ชมพู)

ของใหม่:
- ตาราง **`group_singles`**: `id, group_name, single_name, primary_color, light_color, meta_color, theme jsonb (สีหรือรูปเพิ่มเติม), cover_url, active_from date, is_current boolean`
  - unique `(group_name) where is_current`: แต่ละวงมีซิงเกิลปัจจุบันได้หนึ่งอัน
- หน้าแอดมิน **`admin_singles.html`**: เพิ่มหรือแก้ซิงเกิล ตั้งเป็นซิงเกิลปัจจุบัน และดูตัวอย่างสี
- `get_winner_theme()` ส่ง `theme: {group, single, primary, light, meta, ...}` ของ **Champ ที่ประกาศล่าสุด** (ช่วงเปลี่ยนผ่านจึงตาม Champ สัปดาห์ล่าสุด)
- `applyGroupThemeVars()` ใช้สีจากเซิร์ฟเวอร์ก่อน ถ้าไม่มี ใช้ `GROUP_THEMES` เดิมสำรอง แคชใน localStorage เหมือนเดิม
- ธีมเทศกาลยังเป็นของหน้า Home อย่างเดียว ([[project_blm48_festival_themes_home_only]]) ไม่ชนกัน

### C4. Splash + แบนเนอร์ Home

- `get_winner_theme()` ส่ง `champ` (เดือน) และ `champWeek` (สัปดาห์) และ `champMode`: `'month' | 'transition' | 'week'` คำนวณจาก `app_settings` ฝั่งเซิร์ฟเวอร์ (ไม่ใช้นาฬิกาเครื่อง)
- `index.html` คิว Splash:
  - `month` → Champ เดือน (เหมือนเดิม)
  - `week` → Champ สัปดาห์
  - `transition` → อ่าน localStorage `blm48_champ_splash_turn` (`'month'`/`'week'`) แสดงฝั่งนั้น แล้วสลับค่าสำหรับครั้งถัดไป ถ้าฝั่งนั้นยังไม่มีข้อมูล แสดงอีกฝั่งแทน (เก็บใน localStorage จึงสลับแยกกันในแต่ละเครื่อง)
  - Splash วันเกิดยังขึ้นก่อนเหมือนเดิม
- `champ-splash.js`: `render(container, name, photo, adjust, { kind: 'week' })` → ใช้ป้าย `assets/img/champ-splash/title-week.webp` (รูปจากเอ็มมี่) ที่เหลือใช้ดีไซน์เดิม
- แบนเนอร์ Home: ป้ายเปลี่ยนเป็น "Champ of the Week" แสดงช่วงวันที่แทนเดือน ช่วงเปลี่ยนผ่าน **แสดงตาม Splash ที่เพิ่งขึ้น** ในการเปิดแอปครั้งนั้น
- ไอคอนปุ่มเมนู (`nav_*_url`) เก็บรายเมมเบอร์อยู่แล้ว ใช้กับ Champ สัปดาห์ได้เลย

### C5. Special Fans Day / โพสต์ขอบคุณ

### C7. ปิด Champ รายเดือน + Member Ranking รายสัปดาห์

**หยุดประกาศ Champ เดือน**
- `auto_record_champ_of_the_month()` เพิ่มเงื่อนไข: ข้ามทุกเดือนตั้งแต่ `2027-01` (ค่า `last_monthly_champ = '2026-12'` เก็บใน `app_settings['champ_mode']`) ประกาศธันวาคมวันที่ 1 ม.ค. เป็นครั้งสุดท้าย แล้วเอา cron ออกหลังจากนั้นได้
- `ranking_monthly` ยังนับต่อเพื่อเก็บสถิติ (Member Value, แคมเปญ, ประวัติ) แต่ไม่แสดงเป็นอันดับในแอปแล้ว
- ข้อควรระวัง: `is_month_closed()` ตอนนี้ดูว่าเดือนนั้นมี Champ แล้วหรือยัง เมื่อไม่มี Champ เดือนอีก เดือนจะ "ไม่ปิด" ตลอด ต้องตรวจ `_like_rules_tick` และ `settle_due_member_campaigns` ที่เรียกฟังก์ชันนี้ว่าจะไม่ทำงานผิด อาจเปลี่ยนให้ถือว่า "เดือนปิดเมื่อเลยเดือนนั้นแล้ว" แทน

**Member Ranking บนหน้า Home (ตั้งแต่ 3 ม.ค. 2027)**

- **สีแยกตามวง (เอ็มมี่ 2026-11-24):** อันดับเดียวรวมสองวง แต่ละแท่งเป็นสีประจำวง BLM48 = เหลือง, NPT48 = ฟ้า

  - ปรับให้ตรงสีประจำวงที่ใช้กับกรอบรูป (`GROUP_FRAME_COLORS`): BLM48 `#ffde5b` (ตอนนี้แท่งเป็น `rgba(254,228,121,.4)`), NPT48 `#66cbff` (ตอนนี้ `rgba(106,203,252,.35)`) ใช้ความจางเท่ากันทั้งสองวง

- กติกาจำนวนคุกกี้ (ไลก์ 9 / คอมเมนต์ 9), Fan Score, `kept_likes` ไม่เปลี่ยน

**จุดที่ต้องระวัง**
- cron `like_rules_drip` ไลก์โพสต์เก่าย้อนหลัง หลังเปลี่ยนแล้วคุกกี้ส่วนนั้นจะไปเข้า `cookie_bonus_total` แทนอันดับ (ถูกต้องตามกติกาใหม่)
- `is_month_closed()` ไม่ต้องใช้แล้วหลังเปลี่ยน แต่เก็บไว้สำหรับข้อมูลก่อน 3 ม.ค.

## ส่วน E: Birthday Campaign (แทน Champ Campaign)

ตามรูป iAM48 ที่เอ็มมี่ส่งมา: ไม่มี Champ Campaign แล้ว เหลือแต่ Birthday Campaign ผสมกับระบบเดิม

### E1. เทียบของเดิม vs ใหม่

| | Champ Campaign (เดิม) | Birthday Campaign (ใหม่) |
|---|---|---|
| ใครเปิด | เมมเบอร์เปิดเองจากโปรไฟล์ + วันเกิดเปิดอัตโนมัติ | **ระบบเปิดอัตโนมัติตามวันเกิดเท่านั้น** (ปุ่ม Campaign ในโปรไฟล์และหน้า `campaign_open` เอาออก) |
| ช่วงเวลา | ตั้งแต่เปิดถึงสิ้นเดือน | **จบก่อนวันเกิด** เพื่อให้รางวัล (Splash/Banner วันเกิด) ขึ้นทันช่วงวันเกิด ความยาวประมาณ 15 วันแบบในรูป (ดู E1.1) |
| ยอดรวม | = คุกกี้ใน `ranking_monthly` ของเดือนนั้น | = คุกกี้ที่เมมเบอร์ได้ **ตั้งแต่แคมเปญเปิดจนปิดเท่านั้น** (Gift + โยนคุกกี้ + ไลก์/คอมเมนต์ของแฟน) ไม่นับคุกกี้ก่อนเปิด |
| เป้า / Tier | 10k / 30k / 50k / 100k | **ใช้ของเดิม** 10k / 30k / 50k / 100k |
| รางวัลเมมเบอร์ | ข้อความอย่างเดียว | **Splash Screen** (Tier 1 ขึ้นไป) + **Banner** (Tier 2 ขึ้นไป) ช่วงวันเกิด ไม่มี Balloon Message / ป้ายจริง |
| คืนคุกกี้ให้แฟน | 5 / 10 / 15 / 25% + อันดับ 1 ได้ 100% ถ้าเป็น Champ เดือนเกิด | **5 / 10 / 15 / 25% เหมือนเดิม** + **ซัพพอร์ตเตอร์อันดับ 1 ได้คืน 100% เสมอ** (ไม่มีเงื่อนไข Champ แล้ว) |
| ปุ่ม | Send Cookie | **Send Gift เท่านั้น** เปิดหน้า Gift (ของขวัญ) ที่มีอยู่ ไม่มีปุ่มโยนคุกกี้ในหน้าแคมเปญ |

(เอ็มมี่ตอบคำถาม E5 ครบเมื่อ 2026-11-24)

**รายละเอียดการคืนคุกกี้**
- ฐานคืน = คุกกี้ที่แฟนจ่ายจริงในช่วงแคมเปญ (มูลค่า Gift + โยนคุกกี้) ไลก์/คอมเมนต์ช่วยดัน Tier และอันดับ Top Supporters แต่ไม่คืน (กติกาเดิม)
- อันดับ 1 = ยอดรวมใน Top Supporters สูงสุด (คุกกี้ + ไลก์/คอมเมนต์ เหมือนเดิม) ได้คืน 100% ของฐานคืนของตัวเอง แทน % ตาม Tier ถ้าเท่ากัน ใครถึงยอดนั้นก่อนชนะ
- คืนเมื่อแคมเปญปิด (cron เดิม) ส่งแจ้งเตือนประเภท wallet เหมือนเดิม
- ต้องเพิ่ม `campaign_supports.source = 'gift'` ให้ `send_member_gift` บันทึกเข้าแคมเปญ (ตอนนี้บันทึกแค่ `give_cookie`)

### E1.1 ช่วงเวลาแคมเปญ (เอ็มมี่ยืนยัน 2026-11-24: ต้องจบก่อนวันเกิด)

**หลักคิด:** รางวัลของ Birthday Campaign คือ Splash/Banner วันเกิด ส่วน Champ of the Week เป็นผลพลอยได้ (คุกกี้ช่วงแคมเปญนับเข้าอันดับสัปดาห์ตามปกติด้วย)

ตอนนี้ Splash/Banner วันเกิดแสดง **3 วันก่อนวันเกิด 00:00 ถึงวันเกิด 23:59** ([[project_blm48_birthday_theme_window]])

เอ็มมี่: ความยาว "ตามรูป" = **15 วัน** ข้อเสนอ (วันเกิด = B):
```
 B-18 00:00 ─── แคมเปญเปิด (15 วัน) ─── B-4 23:59 ปิด + สรุป Tier
                                         B-3 00:00 ─ Splash/Banner วันเกิดขึ้นตาม Tier ─ B 23:59
```
- ตัวอย่าง: วันเกิด 20 ม.ค. → แคมเปญ 2–16 ม.ค. → รางวัลขึ้น 17–20 ม.ค.
- แคมเปญปิดแล้วล็อก Tier ทันที (cron `settle_due_member_campaigns` ทุก 5 นาที) ก่อนช่วงแสดงรางวัลเริ่ม
- ถ้าไม่ถึง Tier ที่ได้ Splash → ไม่มี Splash/Banner วันเกิดของคนนั้น (หรือใช้แบบพื้นฐาน ถามเอ็มมี่)
- จำนวนวัน 15 / 3 ตั้งไว้ใน `app_settings['birthday_campaign']` = `{ "length_days": 15, "gap_before_reward_days": 0, "reward_days_before_birthday": 3 }` ปรับได้โดยไม่แก้โค้ด
- เมมเบอร์ที่วันเกิดใกล้กันอาจมีแคมเปญซ้อนช่วงกัน ทำได้ไม่มีปัญหา เพราะแคมเปญแยกตามเมมเบอร์

### E2. หน้าจอ (ตามรูป)
- **การ์ด (Home / View All):** ปกแบนเนอร์ "BIRTHDAY CHAMPION" + ป้ายช่วงวันที่สีเหลือง + รูปเมมเบอร์ตรงกลาง + ชื่อ/วงด้านขวา + ไอคอนเค้กมุมซ้ายบน
  หัวข้อ "มอบ ... เป็นของขวัญวันเกิดสุดพิเศษให้กับ {ชื่อ} {วง}" → แถวตัวเลข `% Funded` / `Supporters` / `Days to go` → แถบ Tier มีจุด 1-2-3 และหัวใจที่ปลาย → `{ยอด} Funded` ซ้าย / `{เป้า}` ขวา
- **หน้า Detail:** ปก + รูปโปรไฟล์วงกลมทับมุมขวาล่าง + หัวข้อ + "by BLM48" + จำนวน supporters → แถบ "Happy Birthday {ชื่อ} {วง}" + คำอธิบาย → แถบ Tier → กล่อง `Days to go` (วัน ชั่วโมง นาที) + ปุ่ม `Top Supporters` → คำอธิบาย + รายการ Tier → ปุ่ม `Send Gift` สีเหลืองติดล่าง
- โครงหน้า `campaign_detail.html` / `campaign.js` เดิมทำจาก iAM48 อยู่แล้ว จึงแก้ต่อจากของเดิมได้ ไม่ต้องสร้างใหม่ทั้งหมด
- ปกใช้ระบบธีมแบนเนอร์รายเดือนเดิม (`CAMPAIGN_BANNER_THEMES`) แต่ใช้เฉพาะแบบ Birthday และธีมตามซิงเกิลของวง (เชื่อมกับ `group_singles` ส่วน C3)
- ทุกข้อความใช้ไอคอน Font Awesome ห้ามอีโมจิ

### E3. ข้อมูล
- `member_campaigns` เพิ่ม `kind` (`'champ'` ของเก่า / `'birthday'`), `start_at`, `goal`, `tiers jsonb` (เก็บเป้าและรางวัลต่อแคมเปญ เปลี่ยนตัวเลขได้โดยไม่กระทบแคมเปญเก่า), `total_cookies_live`
- unique เปลี่ยนจาก `(member_name, year_month)` → `(member_name, kind, start_at)`
- `auto_open_birthday_campaigns()` เปลี่ยนจาก "วันที่ 1 ของเดือน" → รันทุกวัน 00:01 เปิดเมื่อถึง `B-18` ของเมมเบอร์แต่ละคน `end_at = B-4 23:59:59` (ตาม E1.1)
- คิดวันเกิดข้ามปีให้ถูก เช่น วันเกิด 5 ม.ค. → แคมเปญเปิด 18 ธ.ค. ของปีก่อน (เริ่มตั้งแต่ธ.ค. 2027 เป็นต้นไป)
- ไม่เปิดแคมเปญที่วันเปิดก่อน `birthday_campaign.first_open_date = 2027-01-01`
- `settle_due_member_campaigns()` ใช้ต่อ (ปิดแคมเปญที่หมดเวลา, คืนคุกกี้ถ้ายังมี)
- Splash/Banner ที่เป็นรางวัล: เชื่อมกับระบบ Splash/Banner วันเกิดที่มีอยู่ (`splash_bd_url`, `banner_bd_url`) โดยแสดงเมื่อแคมเปญถึง Tier ที่กำหนด
- แคมเปญเก่า (`kind='champ'`) ยังดูย้อนหลังได้ในแท็บ Already Ended
- เมมเบอร์ NPT48 ได้ Birthday Campaign ด้วยหลังเปิดทั้งแอป

### E4. ช่วงเปลี่ยนผ่าน
